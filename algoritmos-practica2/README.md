# GrIA - Algoritmos

Repositorio de código y material para las clases prácticas de **Algoritmos** (Grao en Intelixencia Artificial, USC).

Esta rama (`main`) actúa como rama principal y punto de entrada al repositorio. Cada práctica de la asignatura se encuentra en su propia **rama independiente** (por ejemplo, `practica1`, etc.).

Para consultar o trabajar con el material de una práctica concreta, cambia a la rama correspondiente:

```bash
git checkout practica1
```
